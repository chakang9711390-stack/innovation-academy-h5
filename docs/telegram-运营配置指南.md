# Telegram 群通知配置指南

适用对象：创新学院运营同事  
用途：配置 Telegram Bot，并把课程通知发送到一个或多个指定 TG 群。

## 一、开始前准备

请先准备好：

1. 一个可正常使用的 Telegram 账号
2. 需要接收课程通知的 TG 群
3. 创新学院管理员账号

## 二、创建 Telegram Bot

1. 在 Telegram 中搜索 `@BotFather`
2. 发送 `/newbot`
3. 按提示填写：
   - Bot 名称
   - Bot 用户名，必须以 `bot` 结尾
4. 创建成功后，复制 Bot Token

注意：

- Bot Token 相当于账号密码，不要发到群里，也不要截图外传
- 如果怀疑 Token 泄露，请立刻到 `@BotFather` 重新生成

## 三、把 Bot 加入通知群

1. 打开需要接收通知的 TG 群
2. 将刚创建的 Bot 添加进群
3. 保持 Bot 为普通成员即可，不需要设置为管理员

## 四、获取群 Chat ID

1. 先在群里随便发送一条消息，例如 `/start@你的bot用户名`
2. 在浏览器打开：

   ```text
   https://api.telegram.org/bot你的BotToken/getUpdates
   ```

3. 在返回结果中找到当前群对应的：

   ```json
   "chat": {
     "id": -5111807672,
     "title": "群名称",
     "type": "group"
   }
   ```

4. 复制 `id` 的值，这就是该群的 `Chat ID`

补充：

- 群 Chat ID 通常是负数
- 如果返回结果为空，请先确认：
  - Bot 已加入群
  - 群里已经有人给 Bot 发过消息
  - 当前打开的 URL 中 Bot Token 没有输错

## 五、在创新学院后台配置 TG 群

1. 使用管理员账号登录创新学院
2. 进入 `管理`
3. 打开 `TG 群通知配置`
4. 在 `Bot Token` 中粘贴刚才创建的 Token，点击 `保存 Bot Token`
5. 在 `新增 TG 群` 中填写：
   - `群名称`：便于运营识别，例如 `创新学院直播通知群`
   - `Chat ID`：上一步复制的群 ID
   - `群说明`：可选，例如 `研发内部群`
   - `启用这个群`：需要接收通知时保持勾选
6. 点击 `保存群配置`

说明：

- 支持配置多个 TG 群
- 如果后续还要增加其他群，重复新增即可
- 停用某个群后，该群不会再收到自动通知，也不会出现在手动发送的可选列表中

## 六、手动发送课程通知

1. 进入 `管理`
2. 在课程列表中找到目标课程
3. 点击 `TG 通知`
4. 勾选要发送到的一个或多个 TG 群
5. 点击 `发送到选中 TG 群`

适合场景：

- 临时补发
- 上线前测试
- 只想通知部分群

## 七、开启自动发送

1. 进入 `管理`
2. 打开 `TG 群通知配置`
3. 找到 `自动发送`
4. 勾选 `启用自动发送`
5. 点击 `保存自动发送设置`

开启后，所有已启用群会在：

- 开课前 1 小时
- 开课前 15 分钟

各收到一次课程通知。

关闭后：

- 不再自动发送 TG 消息
- 手动发送功能仍然可以继续使用

## 八、推荐使用方式

### 常规运营

1. 新课程发布后，确认课程信息无误
2. 确认目标群已启用
3. 保持自动发送开启
4. 如需额外提醒，再使用 `TG 通知` 手动补发

### 多群场景

如果不同业务线有不同群：

1. 每个群都单独配置一条记录
2. 群名称写清楚归属，例如：
   - `研发培训群`
   - `运营同步群`
   - `管理层通知群`
3. 需要发给哪些群，就在手动发送时勾选哪些群

## 九、常见问题

### 1. 为什么我发了消息，`getUpdates` 还是看不到群？

请依次检查：

1. Bot 是否真的已经加入目标群
2. 群里是否已经发送过 `/start@你的bot用户名`
3. URL 中是否使用了正确 Bot Token

### 2. 为什么配置后没有自动发送？

请检查：

1. `自动发送` 是否已开启
2. 目标群是否为 `启用`
3. 课程是否已经发布
4. 当前是否已经到达开课前 1 小时或 15 分钟的时间点

### 3. 为什么某个群收不到消息？

请检查：

1. Chat ID 是否填错
2. Bot 是否仍在该群内
3. 该群是否被停用

### 4. Bot 会不会在群里乱回复？

不会。当前产品只会按后台指令主动发送课程通知，没有配置自动回复逻辑。

## 十、安全注意事项

1. Bot Token 不要公开传播
2. Bot 不需要设为群管理员
3. 群配置只建议由管理员维护
4. 不再使用的群请及时停用或删除
